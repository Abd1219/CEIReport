# Product Requirements Document

# Reporte Diario CEI Android

## Objetivo

Desarrollar una aplicación Android para capturar el Reporte Diario CEI y
generar Excel y PDF.

## Problema

-   Captura repetitiva
-   Errores humanos
-   Inserción manual de fotografías

## Usuario

Técnico de campo.

## Alcance

Incluye: - Crear/Editar reporte - Guardar borrador - Fotografías -
Firma - Excel - PDF - Compartir

No incluye: - Nube - Panel web - Usuarios múltiples

## Requisitos funcionales

-   RF-001 Crear reporte
-   RF-002 Editar reporte
-   RF-003 Guardado automático
-   RF-004 Fotografías
-   RF-005 Firma
-   RF-006 Excel
-   RF-007 PDF
-   RF-008 Compartir

## Requisitos no funcionales

-   Android 10+
-   Offline
-   Inicio \<2 s
-   Generación \<5 s
